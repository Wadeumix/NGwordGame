# NGワードゲーム

各プレイヤーのNGワードを自動で選定してくれる、リアルタイム多人数パーティゲームです。
名前を登録 → 部屋を作成（URLで招待）→ 互いに「言いそうなワード」を入力 →
そこから各人のNGワードがランダムに決定 → 各自には自分以外のNGワードだけが表示。
ゲーム中にNGワードを言った人は、全員一斉投票（全会一致）で失格にできます。

## 特徴
- **外部依存ゼロ**（Node.js 標準ライブラリのみ）。`npm install` 不要。
- リアルタイム同期は SSE（Server-Sent Events）+ HTTP POST。
- スマホ・PC のブラウザから参加可能。

## 必要なもの
- Node.js 16 以上（`node -v` で確認）

Node.js が入っていない場合:
- 公式インストーラ: https://nodejs.org/ja から LTS の macOS 版をインストール
- または Homebrew: `brew install node`

## 起動
```sh
cd NGワードゲーム
npm start          # = node server.js
```
ブラウザで http://localhost:3000 を開く。

### 他の端末から参加してもらう（同じWi-Fi内）
Mac の LAN IP を調べる:
```sh
ipconfig getifaddr en0
```
表示された IP を使い、各自のスマホ等で `http://<そのIP>:3000` にアクセス。
部屋作成者が「招待URLをコピー」したものを共有すると、その部屋へ直接参加できます。
（※ コピーされる URL は localhost を含むため、他端末向けには IP に置き換えて共有してください）

## 遊び方
1. 名前を入れて「部屋を作成」。表示された部屋コード／招待URLを友達に共有。
2. 2人以上集まったら、ホストが制限時間とNGワード数を設定し「入力フェーズを開始」。
3. 各プレイヤーが、自分以外の各人へ「言いそうなワード」を複数入力 →「入力完了」。
4. 全員完了または時間切れで、各人のNGワードがランダムに確定。
5. ホストが「ゲーム開始」。各自には自分以外のNGワードが見えます（自分のは秘密）。
6. 誰かがNGワードを言ったら、その人の名前をタップ →「失格にしますか？」→ はい。
   他の全員にも同じ確認が出て、**全員がはい**で初めて失格。1人でもいいえ or 30秒で否決。
7. 最後の1人になると終了。

## ファイル構成
- `server.js` — HTTP/SSE サーバ + ゲームのロジック
- `public/index.html` / `style.css` / `app.js` — フロントエンド
